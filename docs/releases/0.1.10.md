# Quiet.md 0.1.10

## 中文

这次更新改善新建文档、表格编辑和长输入框的使用体验。

- 新建菜单可选择文档、Markdown 或文件夹，快捷新建支持记住上次类型。
- 宽表格新增可拖动的横向滚动条。
- Markdown 表格支持按列对齐，并在保存时保留对齐方式。
- 长输入框跟随光标滚动，修复链接等内容超出后看不到光标的问题。
- 调整文件夹按钮对齐，改善新建文件夹后的命名体验。

新建快捷键的默认类型可在设置中选择「记住上次 / 文档 / Markdown」。

## English

This update improves document creation, table editing, and long input fields.

- Choose Document, Markdown, or Folder from the New menu; quick creation can remember your last choice.
- Drag the horizontal scrollbar to navigate wide tables.
- Align Markdown table columns and preserve alignment when saving.
- Long input fields scroll with the caret, including link fields.
- Align folder buttons and improve naming newly created folders.

Set the quick-create default to Remember last, Document, or Markdown in Settings.

Changes: #102, #145, #152, #153. Thanks to everyone who contributed fixes and reports.

## Packages / 安装包

- macOS: Apple Silicon and Intel ZIPs, Developer ID signed and notarized.
- Windows: x64 installer; unsigned, as in 0.1.9.
- Linux: experimental x86_64 AppImage (glibc 2.35 baseline); updates are manual.

Linux: `chmod +x quiet-md-0.1.10-x86_64.AppImage`, then run it. If FUSE is unavailable, run it with `--appimage-extract-and-run`.

All packages include SHA-256 checksums and detached Minisign signatures, verified with `packaging/update-key.pub`.
